# mapple_build

Open Mapple's build system: `envsetup.sh`, `lunch`, `mka`, the IPSW download, the system image and the
flashable zip. It is being written; for now it holds viva's ADT, boot image, root image and USB link tools
(`tools/`) and HakiOS's IPSW member fetcher (`ios165/`).

Checked out at `build/mapple` by the [Open Mapple manifest](https://github.com/open-mapple/manifest), which says how to get, build and install it.
